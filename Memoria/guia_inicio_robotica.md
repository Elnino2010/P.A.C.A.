* **Tríada de habilidades**: La robótica combina tres elementos esenciales: Informática, Programación y el manejo de hardware físico, requiriendo lógica e ingeniería.
* **Plataformas recomendadas para principiantes**: Se sugiere utilizar plataformas como Arduino o Raspberry Pi, ya que permiten convertir la teoría de código en proyectos físicos reales (conexión con motores y sensores).
* **Rutas de aprendizaje sugeridas**: Para empezar con robótica, Python es el lenguaje más amigable. A nivel avanzado, se recomienda explorar la Inteligencia Artificial (AI) y Machine Learning para entender cómo los algoritmos aprenden patrones.
